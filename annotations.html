The Best PDF Reader with Annotation Features

Finding a lightweight, fast PDF reader is hard enough. Finding one that includes completely free annotation features without watermarks or paywalls is nearly impossible. Enter Nighthawk PDF Reader.

Zero Paywalls, 100% Productivity

Unlike other PDF tools that lock basic markup features behind a premium subscription, Nighthawk offers a full suite of annotation tools directly built into the core experience.

Built-in Annotation Tools:

  • Text Highlighting: Smooth, vector-based highlighting that preserves the underlying text selection.
  • Freehand Drawing: Support for stylus and touch input to markup documents naturally.
  • Sticky Notes: Add collapsible comments anywhere on the document.
  • Export System: Extract all your highlights and notes into a clean, standalone text file with one click.

Built for Speed

Annotations shouldn't slow down your reading experience. By rendering annotations directly via Direct2D alongside the document tiles, Nighthawk maintains 60 FPS scrolling even on heavily marked-up, 1000+ page textbooks.

Native PDF Compatibility. No Proprietary Lock-In.

When you highlight a textbook or sign a legal contract, those annotations belong to you. Unfortunately, many modern PDF readers use proprietary formats or cloud sync layers to save your notes, making it impossible to view them in other applications.

ISO Standard Compliant Metadata

Nighthawk writes all annotations directly into the standard PDF metadata dictionary (ISO 32000 specification). This means every sticky note, freehand drawing, and highlighted passage you create in Nighthawk will render perfectly if you open that same file in Adobe Acrobat, Foxit, Mac Preview, or any other standard PDF viewer.

100% Free Forever

We believe basic document markup is a fundamental right, not a premium feature. Nighthawk will never ask you to subscribe or upgrade just to save a highlighted document. The entire annotation suite—including text extraction, stylus support, and color-coded tags—is permanently free.

Perfect for Students and Researchers

Because annotations are saved natively, Nighthawk integrates seamlessly with reference managers. Export your highlighted PDFs directly into Zotero or Mendeley without losing a single note.
