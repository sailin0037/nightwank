2. Zero-Telemetry & Network Egress Audit

Unlike contemporary PDF applications that spawn 6 to 12 background processes (e.g., Adobe ARM, AcroCEF, Foxit Cloud Connectors) communicating with remote analytics and tracking clusters, Nighthawk PDF Reader is engineered under a strict Zero Egress Guarantee:

  • No Network Socket Import: The core binary rendering pipeline does not import winsock2 (`ws2_32.dll`) or remote HTTP networking libraries during document viewing.
  • Wireshark / Firewall Auditable: You can run Nighthawk inside a sandbox with Wireshark or GlassWire. You will observe exactly zero outbound packets, zero telemetry pings, and zero DNS queries when opening, searching, annotating, or saving documents.
  • Local Hardware Acceleration: GPU rendering is handled strictly on your local hardware via Microsoft Direct2D and DirectX pipelines. No remote rendering servers or AI cloud pipelines are ever contacted.

3. Windows SmartScreen & Code Signing

When running Nighthawk for the first time, Windows Defender SmartScreen may display an "Unknown Publisher" dialog. Here is the technical reason and our transparent policy:

Microsoft requires independent software creators to either pay $400–$800/year to certificate authorities for an Extended Validation (EV) certificate, or build "SmartScreen reputation" over several months of downloads. As an indie project offered 100% free with zero monetization, we prioritize open cryptographic hashes over costly corporate certificates.

To launch safely: Click More info → Run anyway. You can verify the SHA-256 hash above at any time to guarantee full file integrity.
